# A/B-тест нового скрипта разговора в контакт-центре

## Задача
Проверить, влияет ли новый скрипт на FCR и AHT.

## Данные
2000 звонков, две группы (A — старый скрипт, B — новый).

## Что сделано
- Проверка баланса групп по ковариатам (χ²-тесты).
- EDA: описательные статистики, распределения.
- Формулировка гипотез.
- z-тест для долей (FCR), тест Велча для средних (AHT).
- Расчёт размера эффекта и 95% ДИ.
- Ограничения.

## Результаты
| Метрика | A | B | Эффект | p-value | 95% ДИ |
|---|---|---|---|---|---|
| FCR | 63.25% | 67.25% | +4.00 п.п. | 0.0604 | [−0.17; +8.17] |
| AHT | 311.32 сек | 295.17 сек | −16.15 сек | <0.001 | [−19.20; −13.10] |

**Вывод:** снижение AHT статистически значимо; для FCR недостаточно оснований отвергнуть H₀.

## Ограничения
- Нет ID оператора → возможное нарушение независимости наблюдений.
- Нет pre-period → баланс проверен только по ковариатам.
- Эффект по грейдам не проверялся.

## Стек
Python, pandas, scipy, statsmodels, seaborn, matplotlib.
